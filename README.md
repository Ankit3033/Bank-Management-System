# Bank-Management-System
This is a Bank Management System developed using Java (Swing) and MySQL database. The application allows users to perform basic banking operations such as account creation, login authentication, balance enquiry , deposit, and withdrawal. 
The system securely stores user data including card details , passwords, and transaction records using MySQL. It provides a user-friendly interface and demonstrates the use of GUI, database connectivity (JDBC), and event handling in Java.

## Features 
- User Signup & Login Authentication
- Balance Enquiry
- Deposit & Withdrawal
- PIN Verification
- Secure Data Storage using MySQL
- GUI using Java Swing

## Tech Stack
- Java (Swing)
- MySQL
- JDBC

This project demonstrates strong understanding of Java GUI, database connectivity, and banking operations.
